## 🌲 Featured Project

### AI-Assisted Forest Fire Risk Prediction

A graduation project combining multi-source environmental data, machine learning, geospatial analysis, and a Streamlit decision-support interface to estimate short-term forest-fire risk for **İzmir, Muğla, and Antalya, Türkiye**.

[**Explore the project →**](./forest-fire-risk-prediction/README.md)

- **Prediction horizon:** fire occurrence within the following 5 days
- **Spatial unit:** 2 km × 2 km grid cells
- **Models compared:** Random Forest, XGBoost, Balanced XGBoost, LightGBM
- **Methods:** data preparation, feature engineering, model evaluation, geospatial risk mapping
- **Reported final ROC-AUC:** 0.9845 (İzmir), 0.9929 (Muğla), 0.9897 (Antalya)

> This is a research prototype, not an official fire-warning service. The project page documents the reported methodology and results; executable source code and full datasets are not included in the current documentation package.
